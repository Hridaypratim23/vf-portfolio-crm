### What it does

Tracks the full lifecycle of wellness platform clients across India, NA, and international markets — from onboarding through renewals and revenue reporting.

| Feature | Details |
|---|---|
| **Dashboard** | Live stats, AI-style priority insights, donut charts |
| **Client list** | Smart search, tab filters (Active / Subscription / One-time / Churn) |
| **Renewals tracker** | 30 / 60 / 90-day windows + re-run opportunities |
| **FY Revenue** | Multi-currency, fiscal-year breakdown, contributor split |
| **Finance data** | ARR vs one-time vs extra revenue across FYs |
| **Document repo** | Agreement storage, testimonials, sales enablement |
| **Cmd+K search** | Global command palette with smart filtering |
